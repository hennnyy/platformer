## 2. 보류한 MVP 수동 QA

현재 수동 QA가 어려운 상황이므로 아래 두 항목은 개발 진행을 막지 않는 보류 작업으로 관리한다. 테스트 가능한 환경이 준비되면 실행하고 [`MVP_SCOPE.md`](./MVP_SCOPE.md)의 남은 체크박스를 완료 처리한다.

### 2.1 전체 스테이지 수동 충돌 테스트

다음 구간을 키보드와 모바일 터치로 각각 플레이한다.

- 모든 발판의 왼쪽과 오른쪽 모서리
- 낮은 천장 또는 발판 아래에서의 점프
- 벽을 누른 채 점프하고 낙하하는 경우
- 발판 사이를 최대 속도로 이동하는 경우
- 낙사 직전 방향을 바꾸는 경우
- 클리어 직전 재시작하는 경우

완료 조건:

- 플레이어가 발판 안으로 들어가거나 벽에 고정되지 않는다.
- 같은 입력을 반복했을 때 충돌 결과가 일관된다.
- 진행할 수 없는 위치에 리스폰하지 않는다.

### 2.2 실제 디스플레이 주사율 비교

동일한 브라우저에서 60Hz와 120Hz 이상 모니터로 다음 값을 비교한다.

- 1초 동안 최대 속도로 이동한 거리
- 점프 키를 끝까지 눌렀을 때 최고 높이
- 짧게 점프했을 때 최고 높이
- 낙하 후 착지 위치

완료 조건:

- 수평 거리와 점프 높이의 차이가 2px 이내다.
- 체감 게임 속도가 달라지지 않는다.
- 높은 주사율에서 떨림이나 순간 이동이 발생하지 않는다.

## 3. 첫 확장: 경사로 — 구현 완료

### 목표

기존 AABB 발판 이동을 유지하면서 플레이어가 좌우 방향의 직선 경사로를 자연스럽게 오르내리고, 경사면에서 점프할 수 있게 한다.

### 첫 구현 범위

- 올라가는 직선 경사로
- 내려가는 직선 경사로
- 평지와 경사로의 연결
- 경사면 위 접지
- 경사면에서 점프
- 낙하 중 경사면 착지
- 경사면 디버그 선과 접촉점 표시

첫 구현에서 제외:

- 곡선 경사로
- 회전하는 지형
- 움직이는 경사로
- 단방향 경사로
- 천장 경사와 벽 타기
- 경사면에서 미끄러지는 별도 상태

## 4. 경사로 데이터 구조

경사로는 사각형 발판과 분리된 선분 데이터로 관리한다.

```javascript
const LEVEL = {
  platforms: [
    // 기존 사각형 발판
  ],
  slopes: [
    {
      x1: 520,
      y1: 650,
      x2: 620,
      y2: 600,
    },
  ],
};
```

- `(x1, y1)`과 `(x2, y2)`는 경사면의 양 끝점이다.
- 양 끝점의 순서와 관계없이 왼쪽 점과 오른쪽 점을 계산해서 사용한다.
- 경사로 아래쪽은 충돌 가능한 채워진 영역으로 취급한다.
- 첫 버전은 X축 길이와 Y축 높이가 모두 0보다 큰 경사로만 허용한다.

플레이어 중심 X 좌표에서 경사면 높이를 선형 보간한다.

```text
t = (playerCenterX - x1) / (x2 - x1)
slopeY = y1 + (y2 - y1) × t
```

플레이어의 발 위치가 경사면을 통과하고 아래로 이동 중이면 `player.y`를 `slopeY - player.height`로 보정하고 `grounded = true`로 설정한다.

## 5. 경사로 구현 순서

- [x] `LEVEL.slopes` 데이터와 유효성 검사 추가
- [x] Canvas에 경사로 지형과 디버그 선 렌더링
- [x] 플레이어 중심 X에서 경사면 Y를 구하는 함수 작성
- [x] 낙하 중 경사면 착지 처리
- [x] 지상 이동 중 경사면을 따라 높이 보정
- [x] 평지에서 경사로, 경사로에서 평지로 전환 처리
- [x] 경사면에서 점프와 코요테 타임 연결
- [x] 좌우 방향 경사로 테스트 구간 추가
- [x] 키보드와 모바일 입력 회귀 확인

기존 AABB 충돌은 유지했다. 접지 중에는 수평 이동 직후 가까운 경사면 높이를 먼저 반영해 연결 발판의 옆면에 걸리지 않게 하고, 수직 이동 뒤에는 위에서 경사면을 통과한 경우만 착지시킨다.

## 6. 경사로 완료 조건

- [x] 좌우 방향의 경사로를 끊김 없이 오르내릴 수 있다.
- [x] 평지와 경사로 경계에서 캐릭터가 튀거나 멈추지 않는다.
- [x] 경사면에서 멈췄을 때 아래로 가라앉지 않는다.
- [x] 낙하 중 경사면의 시작·중앙·끝 지점에 닿으면 표면 위에 착지한다.
- [x] 경사면에서 점프와 코요테 타임이 평지와 같은 물리 값으로 동작한다.
- [x] 경사로 아래쪽에서 올라올 때 위로 순간 이동하지 않는다.
- [x] 최대 이동 및 낙하 속도에서도 경사면을 통과하지 않는다.
- [x] 모바일 입력도 키보드와 동일한 `Player.update()` 경로를 사용한다.
- [x] 디버그 모드에서 경사 선분과 접촉점을 표시한다.
- [x] 기존 사각형 발판 착지 회귀 검증을 통과한다.

검증은 고정 60Hz 물리 단위 테스트로 수행했다. 실제 기기에서의 최종 조작감과 화면 표시는 2장의 수동 QA와 함께 나중에 확인한다.
