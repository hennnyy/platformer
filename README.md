# Canvas Platformer MVP

게임 엔진과 외부 라이브러리 없이 HTML5 Canvas, CSS, 순수 JavaScript로 만든 2D 플랫포머 MVP입니다.

## 실행

`index.html`을 Chrome, Edge, Firefox 또는 모바일 브라우저로 열면 바로 실행됩니다. 설치나 빌드는 필요하지 않습니다.

## 조작

- `A`, `D` 또는 `←`, `→`: 이동
- `Space`: 점프
- `R`: 스테이지 재시작
- `` ` ``: 디버그 정보 표시

모바일에서는 화면에 표시되는 `←`, `→`, `JUMP`, `↻` 버튼을 사용합니다. 이동 버튼과 점프 버튼을 서로 다른 손가락으로 동시에 누를 수 있습니다.

## 구현된 기능

- 60Hz 고정 시간 물리 업데이트
- 가속과 감속이 적용된 좌우 이동
- 가변 높이 점프
- 코요테 타임과 점프 입력 버퍼
- 사각형 지형 충돌
- 낙사 리스폰
- 카메라 추적
- 도착점과 클리어 화면
- 모바일 반응형 화면과 멀티터치 조작

상세 설계는 [최소 MVP 범위](./docs/MVP_SCOPE.md)와 [플레이어 이동 설계](./docs/PLAYER_MOVEMENT.md)에서 확인할 수 있습니다.
